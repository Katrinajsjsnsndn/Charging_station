🔋 电动工具充电站 UI 设计

核心功能

  • 多子站状态总览
  • 智能功率分配管理 (200W)
  • 多种充电模式 (标准/快充/放电/保养)
  • 电池循环测试与健康评估
  • 3.8V自动保养功能
  • 实时电流电压监控
  • 电池容量与内阻检测
  • 系统参数设置与故障诊断

界面结构

  • 主界面: 子站状态总览 + 功率分配显示
  • 子站详情: 单站详细信息 + 电池健康
  • 功率管理: 智能分配策略 + 功率监控
  • 充电控制: 模式选择 + 实时参数
  • 电池测试: 循环测试 + 容量检测
  • 电池保养: 3.8V保养 + 自动调节
  • 状态监控: 系统参数 + 告警信息
